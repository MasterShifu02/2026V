# Escape Flow Struktur

Dette er escape-flowet med black hole, gåter og låst tilgang før hovedverden.

## Viktige filer

- `src/flows/escape-room/components/BlackHoleEscapeRoom.tsx`: selve escape room-opplevelsen.
- `src/flows/escape-room/content/escapeRoom.ts`: gåter og belønning/billett.
- `src/flows/escape-room/styles.css`: visuell stil for black hole og låste sider.
