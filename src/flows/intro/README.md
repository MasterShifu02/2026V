# Intro Flow Struktur

Dette er intro-flowet med stjerner, tekstsekvens og overgang inn i black hole.

## Viktige filer

- `src/flows/intro/components/StarfieldCanvas.tsx`: canvas-komponenten for stjernebakgrunn.
- `src/flows/intro/hooks/useStarfieldAnimation.ts`: animasjonsmotor for stjerner og tekst.
- `src/flows/intro/content/messages.ts`: tekstlinjene som vises i intro.
- `src/flows/intro/types/timedMessage.ts`: type for tidsstyrte meldinger.
- `src/flows/intro/styles.css`: visuell stil for intro + warp overgang.
